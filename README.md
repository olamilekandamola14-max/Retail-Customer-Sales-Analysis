# Retail Customer & Sales Analysis

## Project Overview

An exploratory data analysis project investigating customer behaviour,
purchasing patterns, income, satisfaction, and customer lifetime value
using Python.

The project demonstrates an end-to-end data analysis workflow, from
data cleaning and transformation to statistical analysis, visualization,
and business recommendations.

## Business Questions

- How does average income vary across regions?
- How do purchasing patterns differ by age group?
- Is customer satisfaction related to income?
- Does customer membership duration relate to lifetime value?
- Is income significantly different between highly satisfied and less
  satisfied customers?

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Analysis Performed

- Data cleaning
- Missing-value treatment
- Duplicate detection and removal
- Customer Lifetime Value (CLV) calculation
- GroupBy analysis
- Pivot tables
- Age-band analysis
- Correlation analysis
- Independent-samples t-test
- Data visualization
